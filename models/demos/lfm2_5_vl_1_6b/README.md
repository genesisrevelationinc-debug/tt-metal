# LiquidAI LFM2.5-VL-1.6B on tt-metal

This directory contains the implementation of [LiquidAI LFM2.5-VL-1.6B](https://www.liquid.ai/), a general-purpose vision-language model for OCR and document comprehension.

## Model Overview

- **Model**: LFM2.5-VL-1.6B
- **Parameters**: 1.6B
- **Architecture**: Vision-Language Model with variable resolution image processing
- **Use Cases**: OCR, document comprehension, visual question answering

## Features

- Text and image processing with variable resolution
- Optimized for Tenstorrent hardware
