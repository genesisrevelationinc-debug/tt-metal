# AudioX Model on Tenstorrent Hardware

This directory contains the implementation of the AudioX model using TTNN APIs on Tenstorrent hardware.

## Features
- Multimodal encoders for text, video, image, and audio
- Multimodal Adaptive Fusion module
- Diffusion Transformer decoder
- Vocoder for waveform generation

## Setup and Running
1. Install dependencies: `pip install -r requirements.txt`
2. Run inference: `python inference.py`
