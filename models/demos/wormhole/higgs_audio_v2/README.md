# Higgs Audio v2 on TTNN

This directory contains the TTNN implementation of Higgs Audio v2, a cutting-edge text-audio foundation model from Boson AI.

## Features
- **Expressive Audio Generation**: Industry-leading emotion and prosody performance
- **Multi-speaker Dialog**: Natural conversations with distinct voices
- **Voice Cloning**: Zero-shot voice cloning from reference audio
- **Diverse Audio**: Speech, sound effects, music, environmental sounds
- **High Performance**: Optimized for TT hardware with 30+ tokens/second
