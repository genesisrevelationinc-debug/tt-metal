# RT-DETR Model Demo

This directory contains the TTNN implementation of RT-DETR (Real-Time DEtection TRansformer) for Tenstorrent hardware.

## Overview

RT-DETR is an end-to-end transformer-based object detector designed for real-time inference. This implementation leverages TTNN APIs to run efficiently on Tenstorrent hardware (Wormhole or Blackhole).
