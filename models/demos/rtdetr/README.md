# RT-DETR Model Implementation

This directory contains the TTNN implementation of RT-DETR (Real-Time DEtection TRansformer) for Tenstorrent hardware.

## Overview

RT-DETR is an end-to-end transformer-based object detector designed for real-time inference. It eliminates non-maximum suppression (NMS) and uses a hybrid CNN–Transformer encoder with dynamic query selection to balance speed and accuracy.
