# LLVC (Low-Latency Low-Resource Voice Conversion) Model Demo

## Overview

This directory contains the implementation of the LLVC model using TTNN APIs for Tenstorrent hardware. The model is designed for real-time voice conversion with ultra-low latency and high efficiency.

## Model Architecture

The LLVC model consists of:
- Lightweight encoder optimized for low-latency inference
- Streaming-capable architecture for real-time processing
- Efficient decoder with support for both F0-dependent and F0-free modes
- Vocoder integration for audio synthesis
