# LLVC (Low-Latency Low-Resource Voice Conversion) Model Demo

This directory contains the TTNN implementation of the LLVC model for Tenstorrent hardware.

## Model Overview

LLVC is a real-time voice conversion model optimized for low latency and CPU efficiency. This implementation enables running LLVC on Tenstorrent hardware (Wormhole or Blackhole) with ultra-low latency and high throughput.

## Features

- Lightweight encoder/decoder architecture
- Streaming and non-streaming inference modes
- Pitch extraction (F0-based and F0-free modes)
- Vocoder integration
- Optimized for real-time applications
